Airbus A320 flight deck 3D model
================================
Source : FlightGear "A320-family" (https://github.com/legoboyvdlp/A320-family, commit fec1ecba767c8fffd145337b27012e89c01e3ade),
         converted to glTF 2.0 by the radebit/flight-simulator project (https://github.com/radebit/flight-simulator,
         public/models/a320/cockpit.glb, commit b2afd173081aea5db00031baa1003aa7c46a789a).

Copyright (c) 2025 Josh Davidson, Jonathan Redpath, merspieler, Matthew Maring, Thorsten Herrmann, Semir Gebran and the
respective FlightGear A320-family contributors.

Distribution: the binary is NOT part of this repository (see AGENTS.md section 5). The unmodified 50.6 MB file (21 PNG/JPEG textures,
no mesh compression) is downloaded by the browser at runtime from the pinned URL listed in src/sim/a320/assets.ts and cached with the
Cache Storage API. cockpit-manifest.json (animation axes / part bounding boxes in the original model coordinates) is loaded from the
same pinned commit via jsDelivr. Neither file is modified by In-Flight; all vertices, UVs, node names and coordinates are the upstream ones.

Runtime-only adjustments made by In-Flight (no change to the source data): texture filtering (trilinear, anisotropic) and an
anti-aliased alpha cut-out shader for the glTF MASK materials (src/sim/a320/cockpitRender.ts).
